# 給 opencode 的提示詞（品保：規範轉檢查清單，Chrome 擴充）

先開一個空資料夾，例如 `我的工具箱/5-小工具/規範轉檢查清單/`，在那裡打開 opencode，整段貼上：

> 幫我做一個 Chrome 瀏覽器擴充（Manifest V3），名字叫「規範轉檢查清單」。
> 用途：我在任何網頁上選一段規範或 SOP 文字，按右鍵選「整理成檢查清單」，就把它切成一條一條可以打勾的項目。
> 規則：
> 1. 依句號、分號、換行、條列編號（1. 2. 或 • －）切開，太短（少於 4 個字）的丟掉
> 2. 含「應、須、必須、不得、禁止、不可、shall、must」的標一個紅色「必要」標籤
> 3. 含「數字＋單位」（mm、%、°C、小時、天、次、件、批、個、kGy、ppm）的標一個藍色「有數字」標籤
> 4. 點工具列上的圖示會打開小視窗，顯示清單，可以打勾，打勾的狀態要記住
> 5. 有一個「複製成文字」按鈕，複製成 ☑／☐ 開頭的清單，最上面附網頁標題和網址
> 不要連網、不要用 AI、不要金鑰。全部用繁體中文。
> 檔案：manifest.json、background.js、popup.html、popup.js、checklist.js。做完告訴我怎麼在 Chrome 裝起來。

## 裝起來（載入未封裝）
1. Chrome 網址列打 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 按「載入未封裝項目」→ 選這個資料夾
4. 隨便開一個網頁，選一段文字 → 右鍵 →「整理成檢查清單」→ 點工具列的拼圖圖示 → 釘選它

> 公司電腦如果「開發人員模式」是灰的，代表 IT 用政策關掉了——改做網頁版（貼文字進去，一樣切成清單）。
